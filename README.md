# Tienda de Maquillaje y Productos Capilares

Tienda virtual desarrollada para la comercialización de productos de maquillaje y cuidado capilar, con opciones de venta al por mayor y al detal.

El proyecto está desarrollado utilizando **HTML5, CSS3 y JavaScript**, con una interfaz enfocada en ofrecer una experiencia de navegación sencilla, moderna y adaptable a diferentes dispositivos.

## Descripción

La aplicación permite a los usuarios explorar un catálogo de productos de belleza, consultar información y precios, seleccionar artículos y gestionarlos mediante un carrito de compras.

La tienda está dirigida tanto a clientes particulares como a clientes mayoristas que necesitan adquirir productos en mayores cantidades.

## Características

- Catálogo de productos.
- Productos de maquillaje.

- Navegación por categorías.

- Modificación de cantidades.

### 1. Clonar el repositorio

```bash

```

### 2. Entrar a la carpeta

```bash
cd tienda-maquillaje
```

### 3. Ejecutar el proyecto

Abrir el archivo:

```text

```

También se recomienda utilizar **Visual Studio Code** junto con la extensión **Live Server** para ejecutar el proyecto durante el desarrollo.

## Uso

Al ingresar al sitio, el usuario puede navegar por las diferentes secciones de la tienda y consultar los productos disponibles.

Para realizar una compra:

1. Ingresar al catálogo.
2. Seleccionar un producto.
3. Agregar el producto al carrito.
4. Modificar la cantidad si es necesario.
5. Revisar los productos seleccionados.
6. Consultar el total.
7. Continuar con el proceso de pedido.

## Modalidades de venta

### Venta al detal

Dirigida a clientes que desean adquirir productos individuales o en pequeñas cantidades para uso personal.

### Venta al por mayor

Dirigida a clientes que desean adquirir productos en cantidades mayores, de acuerdo con las condiciones comerciales establecidas por la tienda.
