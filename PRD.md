# PRD — Tienda de Maquillaje y Productos Capilares

## 1. Información del proyecto

**Nombre del proyecto:** Tienda de Maquillaje y Productos Capilares  
**Tipo de proyecto:** Tienda virtual  
**Modalidad de venta:** Al por mayor y al detal  
**Tecnologías:** HTML5, CSS3 y JavaScript  
**Plataforma:** Aplicación web  
**Estado:** En desarrollo

---

## 2. Descripción del producto

El proyecto consiste en el desarrollo de una tienda virtual especializada en la comercialización de productos de maquillaje y cuidado capilar.

La plataforma permite a los usuarios consultar diferentes productos, conocer sus características y precios, y realizar una selección de artículos para su compra.

La tienda está orientada tanto a clientes particulares que desean comprar productos al detal como a clientes que necesitan adquirir productos en cantidades mayores para uso comercial o personal.

El sitio web busca ofrecer una experiencia de compra sencilla, organizada y visualmente atractiva, facilitando el acceso al catálogo de productos desde diferentes dispositivos.

---

## 3. Problema

Las tiendas tradicionales de productos de belleza pueden presentar dificultades para los clientes al momento de consultar productos, comparar opciones, conocer precios y realizar pedidos.

Además, los clientes mayoristas necesitan una forma sencilla de encontrar productos disponibles en cantidades mayores y conocer las condiciones de compra.

Por esta razón, se plantea desarrollar una tienda virtual que permita presentar el catálogo de manera organizada y facilitar el proceso de selección y compra.

---

## 4. Solución propuesta

Desarrollar una plataforma web para la venta de maquillaje y productos capilares que permita:

- Mostrar un catálogo organizado de productos.
- Presentar información y precios de los productos.
- Facilitar la búsqueda de artículos.
- Permitir seleccionar productos para una compra.
- Diferenciar las necesidades de clientes al detal y mayoristas.
- Proporcionar una interfaz sencilla y atractiva.
- Adaptarse a dispositivos móviles y computadores.

---

## 5. Objetivo general

Desarrollar una tienda virtual funcional y responsive para la comercialización de productos de maquillaje y cuidado capilar, permitiendo a los clientes consultar el catálogo y realizar sus compras de manera sencilla, tanto al por mayor como al detal.

---

## 9. Funcionalidades principales

### 9.1 Página de inicio

Debe presentar la identidad de la tienda y permitir que el usuario acceda rápidamente al catálogo.

### 9.2 Catálogo

El usuario podrá visualizar los productos disponibles y consultar información básica de cada artículo.

### 9.3 Categorías

Los productos estarán organizados de acuerdo con su tipo, por ejemplo:

- Maquillaje.
- Cuidado capilar.
- Tratamientos capilares.
- Accesorios.
- Otros productos de belleza.

### 9.4 Carrito de compras

El usuario podrá seleccionar productos y agregarlos al carrito.

El carrito deberá permitir consultar:

- Producto seleccionado.
- Cantidad.
- Precio.
- Subtotal.
- Total de la compra.

### 9.5 Gestión de cantidades

El usuario podrá modificar la cantidad de productos seleccionados o eliminarlos del carrito.

### 9.6 Modalidad mayorista y detal

La tienda contempla dos tipos principales de compra:

**Venta al detal:** compra de productos individuales o en pequeñas cantidades.

**Venta al por mayor:** compra de productos en cantidades mayores, de acuerdo con las condiciones establecidas por la tienda.

## 11. Requisitos no funcionales

### Usabilidad

La interfaz debe ser sencilla de entender y utilizar.

### Rendimiento

El sitio debe cargar los recursos de manera eficiente y evitar elementos innecesarios que afecten su velocidad.

### Responsividad

La página debe funcionar correctamente en:

- Computadores.
- Tablets.
- Teléfonos móviles.

### Compatibilidad

El proyecto debe poder ejecutarse en navegadores modernos como:

- Google Chrome.
- Microsoft Edge.
- Mozilla Firefox.
- Safari.

### Mantenibilidad

El código debe mantenerse organizado y separado en archivos HTML, CSS y JavaScript para facilitar futuras modificaciones.

## 13. Experiencia del usuario

El flujo básico esperado es:

1. El usuario ingresa a la tienda.
2. Visualiza la página principal.
3. Accede al catálogo.
4. Explora las categorías.
5. Selecciona un producto.
6. Consulta su información.
7. Agrega el producto al carrito.
8. Modifica las cantidades si es necesario.
9. Consulta el total.
10. Continúa con el proceso de pedido o compra.

---

## 14. Diseño

El diseño debe transmitir una identidad relacionada con la belleza, el maquillaje y el cuidado personal.

La interfaz debe priorizar:

- Orden visual.
- Buena presentación de los productos.
- Facilidad de navegación.
- Fotografías de productos.
- Botones claramente identificables.
- Tipografía legible.
- Diseño adaptable a dispositivos móviles.

---

## 15. Criterios de aceptación

El proyecto será considerado funcional cuando:

- La página principal cargue correctamente.
- Los productos se visualicen correctamente.
- Los botones respondan a las acciones del usuario.
- Los productos puedan agregarse al carrito.
- Las cantidades puedan modificarse.
- Los productos puedan eliminarse del carrito.
- Los valores se calculen correctamente.
- El sitio pueda visualizarse correctamente en dispositivos móviles.
- No existan errores críticos en la navegación.
- HTML, CSS y JavaScript estén correctamente relacionados.
